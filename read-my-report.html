Read my report

Upload the PDF, or a photo of each page. Every value is set against its usual range, in plain words. The report is read on your phone and is not uploaded anywhere.

A lab report lists twenty numbers and a column of reference ranges, and still leaves most people none the wiser. This page reads the report you already have, from Caspian or any other lab, and tells you which values are in range, which are worth repeating, and which to show a doctor soon. It covers sugar (HbA1c, fasting and post-meal glucose), the lipid profile with Lp(a), liver and kidney tests, thyroid, vitamin D and B12, the blood count, heart tests (NT-proBNP, echo) and CGM sensor summaries.

1. UploadThe lab's PDF, or a clear photo of each page. Password-protected PDFs open here too.
2. CheckEach value is read off the report. Confirm the numbers against the paper; a photo can lose a decimal point.
3. Work it upOne tap carries the values into the matching calculator on caspianhealthcare.in, our clinic site, with no server in between.

Privacy

The reading software runs inside your browser. The report, and the values read from it, never leave this phone or computer and are not stored anywhere. If you tap through to a calculator, the values travel in the web address after the # sign, which browsers never send to a server. Close the page and it is gone.

What this is, and is not

This is general information to help you read a report, not a diagnosis. One value outside the range is a reason to repeat the test or to discuss it, not a verdict. Ranges are general ones for adults who are not pregnant; where the lab printed its own range it is shown next to the value. If a value is flagged, our physicians at Caspian Healthcare, in the same building, can see you the same day.
